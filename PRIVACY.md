# Privacy contract

Veil is a map that does not collect data about its users. The rules below are requirements
for the code, not intentions: breaking any of them is a bug. They are checked end to end by
[`tests/e2e/privacy.spec.ts`](tests/e2e/privacy.spec.ts) on every pull request, under the
production security headers. Source comments refer to them as `PRIVACY.md §N`.

Русская версия — в [README](README.md#приватность).

## Rules

1. **No third-party requests on load.** Fonts, map glyphs, sprites, icons and map tiles are
   served from the site's own origin. No CDNs, no Google Fonts, no external scripts. A link
   to a place (`#…&place=…`) opens without any request to the geocoder, and a link to a
   route (`#…&route=…`) without any request to the router.
2. **No analytics or error collectors** — none, not even "anonymous" or self-hosted ones.
3. **No cookies, no `localStorage`/`sessionStorage`.** Settings, saved places and offline
   regions live in IndexedDB and the Origin Private File System, on the device only.
4. **Geolocation only on request.**
   - `getCurrentPosition` is called only from the "Where am I" button, and from "Build
     route" when one end of the route is "My location";
   - `watchPosition` runs only in follow mode and stops when it ends, when the map is
     dragged or when the tab is hidden;
   - nothing calls the Geolocation API or `navigator.permissions.query` on its own;
   - the position is never sent to the geocoder (not even as a location bias) and never
     written into the page address — a route from "My location" stores the word `me`;
   - the only time it leaves the device is as the start or destination of a route the user
     builds from "My location", and then only to the router (§10);
   - while the map shows the user's surroundings — after "Where am I", or after fitting a
     route from "My location" — the map center goes neither into the address nor to the
     geocoder, until the user moves the map.
5. **Search sends as little as possible.**
   - a query goes out only after ≥ 3 characters and a 300 ms pause, or only on Enter if the
     user prefers;
   - location bias is the map center rounded to 0.1° (~10 km) and can be turned off;
   - every request has `credentials: 'omit'` and `referrerPolicy: 'no-referrer'`;
   - there is no search history.
6. **Map state lives in the URL fragment** (`#map=…`), which browsers never send to servers.
7. **Strict headers.** `Content-Security-Policy` with `default-src 'self'`, `connect-src`
   limited to `'self'` and the hosts in the runtime `config.json`, no `'unsafe-inline'` or
   `'unsafe-eval'`, `frame-ancestors 'none'`; `Referrer-Policy: no-referrer`;
   `Permissions-Policy` allowing only geolocation for the site itself. Generated by
   [`scripts/build-headers.mjs`](scripts/build-headers.mjs).
8. **The privacy test is mandatory in CI.** It drives the app (load, pan, zoom, search, open
   and save a place, build a route, "What's here?", switch theme and language, a route from
   "My location") and fails on any request to a host outside the allow-list, on any cookie
   or web storage entry, on an unrounded search bias or route point, on the position or a
   map center near it in the address or in a search request, or on any CSP violation.
9. **The app says honestly who sees what** on its in-app Privacy page, naming the hosts of
   the current deployment.
10. **Routes are sent only on request.** The router (`routing` in the runtime `config.json`;
    `null` turns directions off) is asked only when the user taps "Build route" — not when
    a link to a route opens, and not when the form changes. Route points are rounded to
    4 decimals (~10 m); every request has `credentials: 'omit'` and
    `referrerPolicy: 'no-referrer'`. There is no route history, and routes are never
    rebuilt from a watched position.

## Who sees what

Complete anonymity on the web is not possible, and Veil does not pretend otherwise:

| Party                                                                                       | Sees                                                                                                               | How to avoid it                                                           |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| The server hosting the site and map files                                                   | Your IP address and which map areas you load                                                                       | Download regions for offline use, or self-host                            |
| The geocoder ([Photon](https://github.com/komoot/photon) by komoot on the public demo)      | Your IP address, what you type, the rounded map area if location bias is on, the point you pick for "What's here?" | "Search only on Enter", turn location bias off, or run your own Photon    |
| The router ([MOTIS](https://github.com/motis-project/motis) on the deployment's own server) | Your IP address, the start and destination of a route you build (rounded to ~10 m), its time                       | Build routes from places instead of "My location", or run your own router |
| OpenStreetMap                                                                               | Nothing, unless you open one of its links                                                                          | —                                                                         |

## Dependencies

Dependencies that make network requests on their own (analytics, font loaders, CDN loaders,
telemetry) are not accepted.
