# Veil — план проекта (для Claude Code)

> Статус: план согласован 2026-10-02. Этапы 0–2 — готовы. Этап 3 — на ревью (ветка `stage-3`).
> Язык: общение — русский; код, комментарии, коммиты, имена файлов — английский.

## 1. Суть

Веб-карта мира для навигации и ориентирования (аналог Google Maps / Яндекс Карт / 2ГИС), у которой два главных свойства:

1. **Одинаково удобна в браузере на телефоне и на десктопе.** Это сайт (PWA), не нативное приложение.
2. **Полная анонимность.** Никакого сбора данных, телеметрии, аккаунтов, cookies. Геопозиция запрашивается только по явному действию пользователя.

Третье требование — **сменный дизайн**: тема не зашита в проект, новая тема добавляется одним файлом.

## 2. Принятые решения

| # | Решение | Почему |
|---|---------|--------|
| D1 | Данные — **OpenStreetMap**. Google / Яндекс / 2ГИС не используем. | Их условия запрещают использование вне официальных SDK, а SDK передают IP и запросы пользователя этим компаниям. |
| D2 | MVP = **карта + поиск + геопозиция по кнопке + офлайн-карты**. | Выбор автора. Маршруты и пошаговая навигация — после MVP. |
| D3 | Базовый режим — **статический сайт без своего бэкенда**, автор поднимает его бесплатно как демо. | Нулевая стоимость, нечего взламывать, негде хранить данные. |
| D4 | **Опциональный self-hosted сервер** для тех, кто хочет аккаунты и серверные функции. В MVP не реализуется, но фронтенд с первого дня проектируется под него (см. §4.3). | Выбор автора. |
| D5 | Открытый исходный код. Лицензия — открытый вопрос (§11). | |
| D6 | Векторные тайлы в схеме **Protomaps (PMTiles)**, один формат для онлайна и офлайна. | См. §4.1 — это отклонение от первоначального ответа «публичные сервисы напрямую», автор должен подтвердить. |

## 3. Не-цели MVP

- Маршруты, пошаговая навигация, пробки, общественный транспорт.
- Аккаунты, синхронизация, любой серверный код.
- Отзывы, фото, панорамы, рейтинги организаций.
- Нативные приложения и публикация в сторах.
- Офлайн-поиск (только офлайн-просмотр карты; поиск офлайн — после MVP).

## 4. Архитектура

### 4.1. Стек

| Слой | Выбор | Примечание |
|------|-------|------------|
| Сборка | Vite + TypeScript (strict) | Лёгкая сборка, подходит для MacBook Air M2 / 8 ГБ. |
| UI | Svelte 5 | Маленький бандл, мало рантайма. Без SvelteKit — роутинг не нужен, состояние в URL-hash. |
| Карта | MapLibre GL JS | Открытый рендерер векторных карт. |
| Тайлы | PMTiles (`pmtiles` npm) + `@protomaps/basemaps` | Один файл на регион, читается HTTP range-запросами или из локального файла. |
| Поиск | Photon (публичный `photon.komoot.io`) | Геокодер на данных OSM, рассчитан на поиск по мере ввода. |
| Офлайн | Service Worker (`vite-plugin-pwa`) + OPFS для файлов регионов | |
| Локальные данные | IndexedDB (`idb`) | Сохранённые места, настройки. |
| Тесты | Vitest + Playwright | |

**Почему Protomaps, а не тайлы OpenFreeMap напрямую (D6).**
OpenFreeMap отдаёт тайлы в схеме OpenMapTiles, а регионы для офлайна проще всего резать из сборок Protomaps (другая схема). Две схемы = два набора стилей на каждую тему. Одна схема Protomaps даёт:
- один стиль для онлайна и офлайна;
- готовый механизм тем: `@protomaps/basemaps` генерирует слои MapLibre из объекта цветов («flavor») — прямо то, что нужно для сменного дизайна;
- `pmtiles extract` вырезает регион по HTTP, не скачивая планету (120 ГБ) на ноутбук.

Цена решения: файлы `.pmtiles` надо где-то хранить самому (см. §4.4). Запасной вариант, если это не подойдёт: онлайн-тайлы с OpenFreeMap + отдельный генератор стилей под схему OpenMapTiles.

### 4.2. Абстракция провайдеров

Все внешние сервисы — за интерфейсами, адреса берутся из рантайм-конфига `public/config.json` (не из сборки), чтобы self-hosted установка меняла их без пересборки.

```ts
// src/lib/providers/types.ts
export interface TileProvider {
  /** Returns a MapLibre source definition for the base map. */
  source(): Promise<VectorSourceSpecification>;
}

export interface GeocodeProvider {
  search(query: string, opts: { lang: string; bias?: LngLat; signal: AbortSignal }): Promise<Place[]>;
  reverse(point: LngLat, opts: { lang: string; signal: AbortSignal }): Promise<Place | null>;
}

export interface SyncProvider {
  // Reserved for the optional self-hosted server. Not implemented in MVP.
}
```

```jsonc
// public/config.json
{
  "tiles": { "world": "https://tiles.example.org/world.pmtiles" },
  "regions": "https://tiles.example.org/regions/index.json",
  "geocoder": { "type": "photon", "url": "https://photon.komoot.io" },
  "server": null            // set to a base URL to enable account features
}
```

Правило: если `server === null`, UI аккаунтов и синхронизации не рендерится вообще.

### 4.3. Два режима работы

| | Статический (MVP, демо) | Self-hosted (после MVP) |
|-|-------------------------|-------------------------|
| Хостинг | Статика + файлы тайлов | Docker Compose: статика, тайлы, геокодер, API |
| Поиск | Публичный Photon | Свой Photon |
| Аккаунты | Нет | Есть; синхронизация сохранённых мест с E2E-шифрованием (сервер хранит только шифротекст) |
| Данные пользователя | Только на устройстве | На устройстве + шифротекст на сервере |

### 4.4. Хостинг демо

- **Сайт:** Cloudflare Pages (бесплатно; позволяет задать HTTP-заголовки через `_headers`, в отличие от GitHub Pages).
- **Тайлы:** Cloudflare R2 (нулевая плата за исходящий трафик, есть бесплатный объём хранения — **сверить актуальные лимиты и тарифы перед стартом**). В бесплатный объём укладываются обзорный файл мира (низкие зумы) и ограниченный набор регионов. Вся планета до z15 ≈ 120 ГБ — это уже платно (порядка пары долларов в месяц; пересчитать по текущему тарифу).
- Нужен свой домен для R2 (CORS + range-запросы); привязка карты для R2 может потребоваться даже на бесплатном тарифе.

Стартовый набор для демо: `world.pmtiles` (z0–7) + несколько регионов РФ (Москва, Санкт-Петербург и т.п.) до z15. Точные размеры **измерить на этапе 0**.

## 5. Приватность — жёсткие требования

Это требования к коду, а не пожелания. Нарушение любого пункта — баг.

1. **Ноль сторонних запросов при загрузке.** Шрифты, глифы карты, спрайты, иконки — только со своего origin. Никаких CDN, Google Fonts, внешних скриптов.
2. **Никакой аналитики и сборщиков ошибок** (Sentry, Plausible, GA и любые другие), даже «анонимных».
3. **Нет cookies.** Локальное хранение — только IndexedDB / OPFS, только на устройстве.
4. **Геопозиция:**
   - `getCurrentPosition` вызывается только из обработчика клика по кнопке «Где я»;
   - `watchPosition` — только пока включён режим слежения, и останавливается при выходе из него или при сворачивании вкладки;
   - при старте не вызывать ни Geolocation API, ни `navigator.permissions.query({name: 'geolocation'})`;
   - координаты пользователя никуда не отправляются: ни в геокодер, ни в URL.
5. **Поиск:**
   - запрос уходит в геокодер только после ≥3 символов и debounce 300 мс;
   - настройка «искать только по Enter» (отключает поиск по мере ввода);
   - привязка результатов к области — по центру карты, округлённому до 1 знака после запятой (~10 км), и отключается настройкой;
   - история поиска выключена по умолчанию; если включена — хранится только локально.
6. **Состояние карты — в URL-hash** (`#map=12/55.75/37.62`): фрагмент не уходит на сервер.
7. **Заголовки** (`public/_headers`):
   ```
   /*
     Content-Security-Policy: default-src 'self'; connect-src 'self' https://tiles.example.org https://photon.komoot.io; img-src 'self' data: blob:; worker-src 'self' blob:; style-src 'self' 'unsafe-inline'; frame-ancestors 'none'; base-uri 'none'
     Referrer-Policy: no-referrer
     Permissions-Policy: geolocation=(self), camera=(), microphone=(), interest-cohort=()
     X-Content-Type-Options: nosniff
   ```
   `connect-src` генерируется из `config.json` при сборке/деплое.
8. **Автотест приватности** (Playwright): загрузить сайт, подвигать карту, выполнить поиск — и проверить, что все сетевые запросы шли только на хосты из белого списка, а cookies пусты. Тест обязателен в CI.
9. **Страница «Приватность»** в интерфейсе — честно и коротко: что хранится на устройстве, какие сторонние стороны что видят (см. §9).

## 6. Темы

Цель: новая тема = один файл, без правок в компонентах.

- Тема описывается одним объектом:
  ```ts
  // src/themes/types.ts
  export interface Theme {
    id: string;
    name: string;
    scheme: 'light' | 'dark';
    ui: UiTokens;      // colors, radii, shadows, font stack, spacing scale
    map: MapFlavor;    // color set passed to @protomaps/basemaps layers()
  }
  ```
- `ui` превращается в CSS custom properties на `:root` (`--color-surface`, `--radius-md`, …). Компоненты используют **только** переменные — ни одного цвета, радиуса или тени литералом. Проверяется stylelint-правилом.
- `map` передаётся в `layers(sourceName, flavor, { lang })` из `@protomaps/basemaps`; при смене темы вызывается `map.setStyle(...)` с сохранением позиции.
- В MVP — три темы: `light`, `dark` и одна нарочито непохожая (например, высококонтрастная или «бумажная»), чтобы доказать, что система действительно гибкая.
- Выбор темы: по умолчанию — `prefers-color-scheme`; ручной выбор сохраняется локально.
- Иконки — один SVG-спрайт, цвет через `currentColor`.

> Перед реализацией сверить актуальный API `@protomaps/basemaps` (названия `layers` / `namedFlavor`, состав полей flavor) по документации — он менялся между мажорными версиями.

## 7. Офлайн

1. **Оболочка приложения** кешируется Service Worker'ом (precache): сайт открывается без сети.
2. **Регионы.** Заранее нарезанные файлы `regions/<id>.pmtiles` + каталог `regions/index.json` (id, название, bbox, размер, дата сборки). Нарезка — скрипт `scripts/build-regions.sh` на базе `pmtiles extract <build-url> out.pmtiles --bbox ... --maxzoom 15`.
3. **Загрузка региона:** потоковый `fetch` → запись в OPFS из Web Worker (через `createSyncAccessHandle` — он поддерживается шире, чем `createWritable`; проверить актуальную поддержку в Safari). Прогресс, пауза/отмена, проверка `navigator.storage.estimate()` до начала.
4. **Чтение:** источник PMTiles поверх `File` из OPFS; зарегистрировать через `maplibregl.addProtocol('pmtiles', ...)`. Тайл-провайдер выбирает: если точка покрыта скачанным регионом — читать локально, иначе — из сети.
5. **Экран «Офлайн-карты»:** список регионов, размер, дата, удаление, общий занятый объём.
6. `navigator.storage.persist()` запрашивается при первой загрузке региона.

**Ограничения платформ (показывать пользователю):**
- iOS Safari удаляет данные сайта, если его не открывали ~7 дней, **если сайт не добавлен на экран «Домой»**. Перед загрузкой региона на iOS — подсказка установить PWA.
- Квоты хранилища в браузерах ограничены и различаются; большие регионы могут не поместиться.
- Офлайн работает только просмотр карты и сохранённые места. Поиск офлайн — после MVP.

### 7.1. Приложение на экране «Домой» (PWA на телефонах)

Сайт ставится как приложение без магазинов: иконка на экране «Домой», запуск без адресной строки, работа без сети. Сверено 2026-10-02 (источники — в PR этапа 4).

**Общее для обеих платформ**
- `manifest.webmanifest`: `name`/`short_name`, `id`, `start_url: "./"`, `scope`, `display: "standalone"`, `background_color`, `theme_color`, иконки 192 и 512 px + `maskable`-вариант (Android обрезает иконку маской). Никаких сторонних URL в манифесте.
- `<meta name="theme-color">` обновляется при смене темы (цвет строки состояния), учитывать `prefers-color-scheme`.
- В режиме `standalone` нет кнопки «Назад» браузера: `Esc`/«назад» в интерфейсе уже есть (карточка → результаты → список); на Android системный «Назад» должен закрывать карточку/sheet, а не приложение — через `history` (по одному шагу на открытую карточку).
- Ссылки наружу (OSM) открываются в браузере, а не внутри приложения (`target="_blank"` — уже так).
- Подсказка «Установить приложение» — ненавязчивая, в настройках и перед загрузкой офлайн-региона; факт «подсказку закрыли» хранится только локально.

**Android (Chrome, Samsung Internet, Firefox)**
- Chrome сам предлагает установку при наличии манифеста и HTTPS; перехватываем `beforeinstallprompt`, чтобы показать свою кнопку «Установить» в нужный момент.
- Установленное приложение делит хранилище с сайтом в браузере (тот же origin) — сохранённые места и регионы общие.
- `navigator.storage.persist()` у установленного приложения обычно одобряется без вопроса.

**iOS / iPadOS (Safari)**
- Установка только вручную: «Поделиться» → «На экран „Домой“». `beforeinstallprompt` нет — показываем короткую инструкцию с картинкой. С iOS 26 сайт по умолчанию открывается как веб-приложение (переключатель «Открыть как веб-приложение»).
- **Отдельное хранилище:** у приложения с экрана «Домой» своё хранилище, не общее с Safari. Сохранённые места и регионы, скачанные в Safari, в приложении не появятся. Поэтому: подсказывать установить приложение **до** загрузки регионов; для переноса мест — экспорт/импорт GeoJSON (уже есть).
- Только установленное приложение защищено от удаления данных через 7 дней без посещений; `navigator.storage.persist()` в Safari работает только для него.
- Геопозиция: в установленном приложении iOS может спрашивать разрешение в каждой новой сессии; известны баги, когда запрос не показывается в `standalone`. Проверить на реальном устройстве; при зависании запроса — понятное сообщение по таймауту (таймаут уже 15 с).
- Иконка: `apple-touch-icon` 180 px (iOS берёт её, а не иконки манифеста). Заставки (`apple-touch-startup-image`) — не делаем: десятки размеров ради секунды загрузки.
- `viewport-fit=cover` и `safe-area-inset-*` — уже учтены (вырез, «чёлка», полоска «Домой»).

**Проверка на устройствах (этап 5):** установка, запуск в `standalone`, тема строки состояния, «Назад» на Android, геопозиция после перезапуска на iOS, офлайн-запуск в режиме «в самолёте», сохранность данных после недели без запуска.

## 8. Интерфейс

- **Телефон:** карта на весь экран; поиск — плавающая строка сверху; результаты и карточка места — bottom sheet с тремя положениями (свёрнут / половина / полный), управляется жестом; кнопки «Где я», зум и слои — справа снизу в зоне большого пальца; учитывать `env(safe-area-inset-*)`.
- **Десктоп:** левая панель фиксированной ширины (поиск, результаты, карточка), карта — всё остальное; управление с клавиатуры (`/` — фокус в поиск, `Esc` — закрыть, стрелки — по результатам).
- Один набор компонентов, раскладка переключается container queries, а не отдельными версиями.
- Доступность: контраст ≥ 4.5:1 во всех темах, видимый фокус, `prefers-reduced-motion`, область нажатия ≥ 44 px.
- i18n: `ru` и `en` с первого дня (простые JSON-словари, без тяжёлых библиотек); язык подписей на карте следует языку интерфейса.
- Атрибуция «© OpenStreetMap» обязательна и всегда видна на карте.

## 9. Риски и честные ограничения

| Риск | Что это значит | Что делаем |
|------|----------------|------------|
| «Полная анонимность» не абсолютна | Хостинг сайта и тайлов видит IP и запрашиваемые участки карты; Photon видит IP и текст поиска. | Честно написать на странице «Приватность»; поиск только по Enter как опция; офлайн-регионы убирают запросы тайлов; self-hosted режим убирает третьих лиц полностью. |
| Публичный Photon — без гарантий | Fair use: при активном использовании запросы режут, доступность не гарантируется. | Debounce, отмена запросов, понятное сообщение об ошибке; адрес геокодера — в конфиге. **Сверить условия на photon.komoot.io перед запуском.** |
| Поиск организаций слабее Яндекса/2ГИС | В OSM меньше POI, часы работы и телефоны часто отсутствуют. | Не обещать в интерфейсе того, чего нет; показывать ссылку «Исправить в OpenStreetMap». |
| Объём тайлов | Планета ~120 ГБ; бесплатного хранилища хватит только на обзор мира и несколько регионов. | Демо с ограниченным покрытием на высоких зумах; за пределами — явная подпись «детальная карта для этой области не загружена». |
| Ограничения браузеров для офлайна | См. §7. | Подсказки и проверки квоты. |
| Доступность сервисов из РФ | Cloudflare и зарубежные сервисы могут работать нестабильно. | Адреса в конфиге; self-hosted режим позволяет разместить всё на любом сервере. |
| Вес MapLibre | ~250 КБ gzip — заметно на слабых телефонах. | Ленивая загрузка всего, кроме карты; бюджет бандла в CI. |

## 10. Этапы

Каждый этап — отдельная ветка и PR, заканчивается рабочим состоянием.

**Этап 0 — прототип и замеры**
- Каркас Vite + Svelte 5 + TS, ESLint, Prettier, stylelint, Vitest, Playwright.
- MapLibre + локальный маленький `.pmtiles` (один город), стиль из `@protomaps/basemaps`.
- Скрипт `scripts/build-regions.sh`; замерить размеры: мир z0–7, Москва, СПб, одна область целиком, при maxzoom 14 и 15.
- *Готово, когда:* карта города открывается локально, таблица размеров записана в `docs/tile-sizes.md`.

**Этап 1 — карта и темы**
- Система тем (§6), три темы, переключатель.

## 13. Правила для Claude Code
