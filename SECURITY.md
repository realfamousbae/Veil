# Security / Безопасность

## Reporting a vulnerability

Please report security and privacy issues **privately** through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue.
A privacy leak (a request to an unexpected host, a stored identifier, the user's position
reaching a server or the URL) counts as a vulnerability — see [PRIVACY.md](PRIVACY.md).

## Сообщить об уязвимости

Сообщайте о проблемах безопасности и приватности **закрыто** через GitHub:
**Security → Report a vulnerability** в этом репозитории, а не в публичных issues.
Утечка данных (запрос на неожиданный хост, сохранённый идентификатор, попадание
местоположения пользователя на сервер или в адрес страницы) — тоже уязвимость,
см. [PRIVACY.md](PRIVACY.md).
